[GH #324]
Implicit "this" in a default member initializer with a nested aggregate

When the default member initializer of an aggregate class contained an
aggregate initialization of another object of the same class, an implicit use
of "this" in the elements of that nested initialization referred to the
nested object instead of to the object being initialized.  This affected
initializations that are not folded to constants, such as those in
new-expressions or return statements.  For example:

  struct Y { unsigned k; unsigned n = Y{2, k}.n; };
  Y *p = new Y{1};  // p->n is now 1 (previously 2).

This is now fixed.
